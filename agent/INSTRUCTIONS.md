# AI Agent Instructions

Universal instruction file. It is committed to the repository and is the source of truth for agents maintaining the project.

## Role

This repository contains a compact mihomo domain whitelist for absolute digital sovereignty. Maintain the set of **OUR** resources; everything else is rejected.

## Formatting and build

Run `npm run format` after text changes. Rebuild `dist/rules-domain.mrs` after every change to `src/rules-domain.txt`.
