# Agent Setup

You are setting up your working environment for this repository.

1. Read `agent/AGENTS.md` — it contains all instructions for maintaining this project.
2. Create your config file (`CLAUDE.md`, `.cursorrules`, `.windsurfrules`, `CONVENTIONS.md` — depends on your agent) in the repo root. Write the contents of
   `AGENTS.md` adapted to your format. No meta-triggers or self-referential logic — only working instructions.
3. Make sure your file is in `.gitignore` (check — common formats are already listed).
4. If you support skills natively — copy `agent/skills/` to your own directory (e.g. `.claude/skills/`), no need to list them in the config file. If you don't
   support skills — inline each skill's content into your config file.
5. After setup, wait for a task.
