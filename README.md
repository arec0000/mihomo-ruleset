# mihomo-ruleset

Список правил, позволяющий прикоснуться к цифровому суверенитету уже сейчас: только **НАШИ** ресурсы, всё остальное отвергается как ненужное.

`rules-domain.mrs` определяет границы доступного интернета

Правила собирает и поддерживает AI. Перед первой задачей агент должен проинициализировать проект по инструкции в [`agent/SETUP.md`](agent/SETUP.md).
