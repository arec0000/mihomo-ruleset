# mihomo-ruleset

Набор правил маршрутизации для mihomo, который помогает заблокировать сайты самостоятельно — не дожидаясь, пока это сделают провайдеры или сами сервисы.

Список **компактный** — часть сервисов намеренно не добавлена, чтобы не раздувать набор. Универсальные агрегаты:
[itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains),
[runetfreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat),
[dartraiden/no-russia-hosts](https://github.com/dartraiden/no-russia-hosts), [Loyalsoldier/v2ray-rules-dat](https://github.com/Loyalsoldier/v2ray-rules-dat),
[MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat).

Правила собирает и поддерживает AI. Перед первой задачей агент должен проинициализировать проект по инструкции в [`agent/SETUP.md`](agent/SETUP.md).
