# Не добавляем

Пусть блокировкой этих сервисов занимаются провайдеры и сами сервисы — свои ресурсы тоже не резиновые. Сверяться перед расширением.

## Сервисы

- Signal
- Proton

## Группы

- Проприетарные VPN-сервисы
- Букмекеры и казино
- ЛГБТК+ ресурсы
- Нелегальный контент (наркошопы, даркнет, оружие, фальшивые документы, экстремизм, терроризм, CSAM, фишинг, malware, скам)
- Торрент-трекеры
- SMS-активаторы, фейковые номера
- Порно
- Религиозные ресурсы
- Региональные блоги, персональные сайты иноагентов
- Локальный ретейл США без аудитории в РФ
- Нишевые стриминги без русскоязычной аудитории
- IP-check и сервисы, косвенно раскрывающие IP (speedtest/ookla, ipify, ipinfo, ip-api, ifconfig.me, icanhazip, whatismyip, whoer, browserleaks, fast.com,
  nperf, cloudflare cdn-cgi/trace и т. п.)

## Технические ограничения для ipcidr

- **Viber** — нет чисто-Viber префиксов, сервис на Akamai/AWS. Только домены
- **Полные AS Cloudflare / AWS / GCP / Azure** — только узкие срезы, не весь AS
- **AS49544 (I3D.net)** — только `2a0e:5940::/29` (Discord-собственный), не весь AS
- **Широкие /16 в публичных облаках** — поймают чужой трафик
