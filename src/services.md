# Реестр сервисов в курированных списках

Плоский реестр всех сервисов, для которых в `rules-domains.mrs` и `rules-ipcidr.mrs` есть правила. Пометка `(+IP)` означает, что для сервиса работает также
ipcidr-правило, а не только домены. Ревизия: 2026-04-16.
