# Референсные источники

## Доменные зоны

- [IANA Root Zone Database](https://www.iana.org/domains/root/db) — актуальный реестр TLD
- [Координационный центр доменов .RU/.РФ](https://cctld.ru/) — российские национальные домены
- [v2fly/domain-list-community: tld-ru](https://github.com/v2fly/domain-list-community/blob/master/data/tld-ru) — перечень российских TLD в формате geosite

## Российские сервисы

- [v2fly/domain-list-community: category-ru](https://github.com/v2fly/domain-list-community/blob/master/data/category-ru) — community-категория российских
  компаний и сервисов
- [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat) — сборки geosite для mihomo
- Официальные сайты, документация и страницы статуса сервисов — основной источник для подтверждения выделенных доменов и CDN

## Проверка изменений

- Новые домены в международных зонах добавляются только при подтверждённой принадлежности российскому сервису
- Community-списки используются как источник кандидатов, а не копируются целиком
- Общие облака, CDN, рекламные сети и аналитика исключаются, если домен нельзя безопасно связать с одним российским сервисом
